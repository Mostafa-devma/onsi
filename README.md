# ONSI — أُنسي · Home Kitchen

Scroll-animated one-page website for [@onsi_kitchen](https://www.instagram.com/onsi_kitchen/): daily home-cooked meals, 10 AM – 5 PM, delivery available.

Plain HTML/CSS/JS, no build step. Open `index.html` or serve the folder with any static host (e.g. GitHub Pages).

- Animations: GSAP 3.12.5 + ScrollTrigger, Lenis smooth scroll (CDN)
- Fonts: Fraunces, Manrope, Aref Ruqaa (Google Fonts)
- Photos in `assets/img/` are Unsplash stand-ins — replace them with ONSI's own photos using the same filenames.
